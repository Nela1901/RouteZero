## 4. Nivel 4 — Diagrama de Código (Motor de Optimización ACO)

Muestra la estructura interna del componente crítico del sistema: el motor de optimización ACO.

```mermaid
graph TD
    subgraph Motor ACO - VRPTW + Green VRP
        IN[Input\nPedidos + Vehículos + Restricciones]
        
        subgraph Inicialización
            FER[Matriz de Feromonas\nInicialización uniforme]
            HEU[Matriz Heurística\nDistancia + Ventanas de tiempo]
        end

        subgraph Ciclo de Hormigas
            CH[Construcción de Solución\nSelección probabilística]
            EV[Evaluación\nDistancia + CO₂ + Penalizaciones]
            AC[Actualización de Feromonas\nEvaporación + Depósito]
        end

        subgraph Criterio de Parada
            IT[¿Iteraciones completadas?\no ≤ 45 segundos]
        end

        OUT[Output\nRutas óptimas por vehículo]
    end

    IN --> FER & HEU
    FER & HEU --> CH
    CH --> EV --> AC --> IT
    IT -->|No| CH
    IT -->|Sí| OUT
```
